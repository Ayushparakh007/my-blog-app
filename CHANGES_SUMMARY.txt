================================================================================
SECURITY FEATURES ADDED
================================================================================

1. Role-Based Access Control
   - Users only login to /user/login
   - Admins only login to /admin/login
   - Mixing roles will be rejected

2. Admin Secret Key
   - Required to create admin accounts
   - Configured in .env (ADMIN_SECRET)
   - Prevents unauthorized admin creation
   - Default: admin-secret-key-2024

3. Password Validation
   - Password confirmation field in registration
   - Passwords must match before creating account
   - Still using bcrypt with 10 salt rounds

4. Clear Role Assignment
   - User registration: role = 'user' (automatic)
   - Admin registration: role = 'admin' (automatic)
   - No role selection in UI
